# METODOLOGÍA TDD

## Aplicada a los proyectos de cálculo de IVA y cálculo de descuento

## Lista de escenarios: Cálculo de IVA

1. El valor del producto es un valor mayor a cero y se regresa el número correspondiente al valor del IVA.
2. El valor del producto es un valor menor a cero y se regresa `0` como resultado.
3. El valor del producto es un valor igual a cero y se regresa `0` como resultado.

## Lista de escenarios: Cálculo de descuento

1. El valor del producto es mayor a cero: se calcula y regresa el monto correspondiente al descuento aplicado al producto.
2. El valor del producto es menor a cero: no se realiza el cálculo del descuento y se regresa `0.0` como resultado.
3. El valor del producto es igual a cero: no se aplica ningún descuento y se regresa `0.0` como resultado.
